# अनुसन्धान-लेखाः सङ्ग्रहाश्च

स्वचालित-साहित्य-दत्तनिरीक्षणानां नियमितं मूल्याङ्कनं, संश्लेषणं, संक्षेपणं च। स्वचालितम् इत्यस्य तात्पर्यम् अस्ति यत् स्रोतांसि गुणवत्ता-मानदण्डानाम् आधारेण चितानि सन्ति, किन्तु योग्य-विशेषज्ञैः तेषां पुनरीक्षणं वा प्रत्यक्ष-सत्यापनं न कृतम्।

::: details "OIT vs. AMT" इत्यस्य कः अभिप्रायः? (आउट ऑफ इंडिया थ्योरी विरुद्धम् आर्य-प्रवासन-सिद्धान्तः)
**OIT vs. AMT** भाषावैज्ञानिकस्य जनसांख्यिकीयस्य च इतिहासस्य द्वयोः प्रतिस्पर्धिनोः प्रतिरूपयोः (Models) मध्ये अनुभवसिद्धं तारतम्यं निरूपयति:

- **OIT (Out of India Theory / भारत-मूल-सिद्धान्तः):** भारोपीय-भाषापरिवारस्य मूलस्थानं भारतीयोपमहाद्वीपः आसीत्, तत एव पश्चिमाभिमुखं मध्य-एशिया-दिशि च विस्तारः सञ्जातः इति प्रतिपादयति।
- **AMT (Aryan Migration Theory / स्टेपी-परिकल्पना):** भाषावैज्ञानिकः पुराजनुवैज्ञानिकश्च सर्वसम्मतः सिद्धान्तः, येन द्वितीय-सहस्राब्द्यां ईसापूर्वे यूरेशिया-स्टेपी-प्रदेशात् मध्य-एशिया-मार्गेण हिन्द-ईरानी-भाषकाः दक्षिण-एशियाम् आगताः इति वर्ण्यते।
:::

::: details "IVC" (सिन्धु-उपत्यका-सभ्यता / हरप्पा-संस्कृतिः) किम् अस्ति?
**IVC (Indus Valley Culture / Civilization)** उत्तर-पश्चिम-दक्षिण-एशिया-विभागे कांस्ययुगीनां सिन्धुसभ्यतां (प्रायः ३३००–१३०० ईसापूर्वम्) निर्दिशति (यथा: हरप्पा, मोहेञ्जोदड़ो, धोलावीरा, राखीगढ़ी, लोथल इत्यादयः):

- **मासिक-वृत्तान्तानां लक्ष्यम्:** नूतन-पुरातात्त्विक-उत्खनन-फलितानां, कार्बन-कालनिर्धारणानां, प्राचीनजनुसूत्र-प्रतिदर्शानां (aDNA), पुरा-जलवायु-दत्तांशानां (अवसाद-क्रोड-प्रवृत्तयः, वर्षर्तु-परिवर्तनानि), तथा व्यापार-सम्बन्धानां, नगरीकरण-विनगरीकरण-प्रक्रियाणां च निरन्तरं संश्लेषणम्।
- **सङ्क्षेप-नाम:** सर्वेषु लेखेषु मेटादत्तांशेषु च अन्तर्राष्ट्रीय-मान्यं **IVC** इति सङ्क्षिप्तनाम प्रयुज्यते।
:::
